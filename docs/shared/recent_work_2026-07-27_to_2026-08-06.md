## 1. 当前研究结论

最近十天完成了从“相关性”到“干预效用”再到“失败机制定位”的闭环：

```text
Thought 1：环境 OOD 行为缺口
    97.25% Clean → 47.70% OOD；Camera 15.13%
                         ↓
Thought 2：shadow future 观察关联
    OOD future distance +0.0316；motion direction −0.1898
                         ↓
Thought 3 Phase 1：future-content 动作反事实
    correct/null/shuffle 在 8/8 样本上改变动作
                         ↓
Thought 3 Phase 2：matched held-out utility
    K=1 比 K=0 loss 高 3.624%，4/4 development 更差；停止
                         ↓
Thought 4：Camera geometry–action 机制定位
    Camera gap 0.020273 m > Lighting 0.011660 m；36/36 可逆干预
                         ↓
Thought 5：针对性 GeoEq Pilot
    gap 缩小 20.94% < 25%；future utility −0.005231；Camera 1/4=1/4
                         ↓
只读失败分解
    伤害集中于 Clean/低 sigma；RayPose 执行非零但独立因果未识别
```

最强且不过界的总论断是：

> **Future sensitivity is not future utility.** Fast-WAM 在所测环境 shift 下存在
> 大幅鲁棒性缺口；future proxy 会在 OOD 下变差，future 内容也能改变动作，但
> 所测 K=1 Adapter 与 GeoEq 配方均未把这种敏感性稳定转化为 held-out 或闭环收益。

这不是“未来普遍无用”的证明。当前证据只覆盖指定 Fast-WAM checkpoint、单个
轻量 Adapter 配方、Thought3 的单 task 28/4 离线对照，以及 Thought5 的单 task
方向性 Pilot。

## 4. 论文逻辑链条

论文不是“提出一个模型并刷分”，而是识别一组经常被混写的命题：

1. **OOD robustness：** 标准成功率高不代表环境鲁棒。
2. **Prediction association：** future proxy 与失败相关不代表 future error 导致失败。
3. **Action sensitivity：** 输入干预改变动作不代表改变方向有益。
4. **Held-out utility：** 只有 matched 训练/评测才能检验 future 是否有用。
5. **Mechanism localization：** 负结果后应先定位 representation/interface gap，而非盲目增加 K。
6. **Targeted intervention：** 针对性方法也必须通过 specificity、utility 与 rollout 三重门禁。
7. **Stopping discipline：** 未过方向 Gate 时保留负结果，避免用 formal 预算和 outcome 继续搜索答案。

论文价值因此有两层：实证上给出 Fast-WAM 的环境 OOD 缺口与两个连续负结果；
方法上给出一套从行为、关联、技术干预、效用、机制到针对性方法验证的分层审计框架。

## 6. 固定边界与下一问题

可以写：

- 所测 Fast-WAM checkpoint 对五类环境 shift 敏感，Camera 最严重。
- shadow future proxy 在 OOD 下变差并与失败相关。
- K=1 future 内容在固定样本上改变动作。
- 所测 K=1 Adapter 和 G3 GeoEq recipe 未形成正 held-out/Pilot utility。
- Thought4 支持 Camera equivariance gap，Thought5 将新假设收窄到
  condition-aware/low-noise fusion 与 RayPose/共享正则化识别。

不能写：

- “future error 导致 Fast-WAM 失败”或“future 普遍无用”。
- “Geo-REPA 无效”或“Camera equivariance 不是因果机制”。
- 把 Thought3 `8/8`、Thought4 `36/36` 或 Thought5 `1/4` 当作总体成功率结论。
- 在同一 Pilot 上放宽 25% 门槛、忽略 G4、选择 checkpoint 或直接启动 formal。

下一项研究若启动，必须建立新预注册、新 namespace 和未使用 cohort；优先做单变量
condition-aware/low-noise mitigation，以及 matched gate-zero/G1/G2 对照来拆分
RayPose、Geo-REPA correspondence 与共享正则化。
